# PRP Portal - Team Integrated Project

Integrated team flow:
1. Login
2. Forgot Password
3. Reset Link Sent
4. Password Reset Success
5. Back to Login

## Run
npm install
npm run dev

## Routes
- /PRP_Portal/Login
- /PRP_Portal/ForgotPassword
- /PRP_Portal/ResetPassword
- /PRP_Portal/PasswordResetSuccess
